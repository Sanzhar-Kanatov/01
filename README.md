# My Branching Repo

## Жоба туралы
Бұл жоба Git жүйесіндегі тармақтармен (branches) жұмыс істеуді үйрену мақсатында
жасалған оқу репозиторийі.

## Жобаның мақсаты
- жаңа тармақтар құру және олардың арасында ауысу;
- өзгерістерді тармақтарға коммит ету;
- тармақтарды біріктіру (merge);
- біріктіру кезінде туындайтын қайшылықтарды (конфликттерді) шешу;
- біріктірілген тармақтарды жою.

## Жоба құрылымы
- README.md – жобаның сипаттамасы;
- feature-a.txt – feature-a тармағында жасалған файл;
- feature-b.txt – feature-b тармағында жасалған файл.

## Жұмыс барысы
1. master тармағында бастапқы коммит жасалады.
2. feature-a және feature-b тармақтары құрылып, оларға файлдар қосылады.
3. Тармақтар master тармағына біріктіріледі.
4. feature-a.txt файлында қайшылық туғызылып, ол шешіледі.
5. Біріктірілген тармақтар жойылады.

## Қажетті бағдарламалар
Git және мәтіндік редактор (мысалы, Visual Studio Code).
